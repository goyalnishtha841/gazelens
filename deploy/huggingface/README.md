# GazeLens API

The FastAPI backend of [GazeLens](https://github.com/goyalnishtha841/gazelens):
webcam gaze estimation, gaze-to-element attribution, multi-agent UX analysis and
PDF reports. The web app itself is deployed separately.

**This Space is deployed automatically from GitHub** by
`.github/workflows/deploy-hf.yml`, so don't edit files here; change them in the
GitHub repo instead. Health check: `/health`. API docs: `/docs`.
